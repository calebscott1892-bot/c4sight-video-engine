# C4Sight — Figma Make Master Prompt

Paste this into Figma Make as the project brief. Attach the Show Bible markdown to the project too — Figma Make will reference it.

This prompt is structured so each deliverable can be requested separately if Figma Make struggles with the full scope in one shot. Run them in order; later deliverables build on earlier ones.

---

## Project Context

C4Sight is a YouTube channel explaining AI clearly, practically, and without hype. Adult, intelligent, slightly dry tone. Visual identity is illustrated, textured, and hand-feeling — not flat motion graphics, not corporate SaaS, not childish.

The show has four visual modes (Main Animated World, Blackboard, Interface/Tool, Human Judgement). It has one mascot (a tiny alien wizard) and one host character. See the attached Show Bible for full creative direction. Where this prompt and the Show Bible disagree, the Show Bible wins.

This Figma project is the visual foundation for Episode 1 and the channel manifesto.

---

## Visual Identity Anchors

**Palette (locked, no others):**
- Slate `#1A1F1C` — blackboard, dark mode
- Chalk `#F4EDE0` — chalk text, primary type on dark
- Paper `#EFE7D6` — main world background
- Verify Red `#D7382C` — stamp, warnings, emphasis
- Wizard Lavender `#B9A8C7` — alien wizard
- Ink `#221F1F` — line art, host on light backgrounds

No gradients. No glows. No neon.

**Typography:**
- Display: humanist slab serif (Recoleta, Domaine Display, Tiempos family)
- Body: grounded geometric sans (Söhne, GT America, Inter)
- Chalk: hand-illustrated, not a chalk-effect font

**Line weight:** 2.5–3pt main world, hand-drawn for blackboard, 1.5pt for UI mode.

**Texture:** every scene has subtle paper or fabric grain. The world looks like it was *drawn*, not exported from a vector library.

## Deliverable 1 — Mascot Character Sheet (Tiny Alien Wizard)

A single board with:

1. Front view (full body, neutral expression)
2. 3/4 view, left
3. 3/4 view, right
4. Side profile
5. Six expression studies: neutral, sulking, panicked, smug ("told you so"), disappointed, mid-shrug
6. Three pose studies: trying to take credit (chest puffed, hands gesturing), being debunked (slumped), stealing the chalk wand (sneaky)
7. Scale reference next to a coffee cup, a hand, and the host

**Design constraints (mandatory):**
- Pale lavender body (#B9A8C7), slightly translucent.
- Pointy hat in slate, with stars that are *almost right* — a triangle, a wonky pentagon, an uneven five-pointed star. Three stars max.
- Robe is too long, drags slightly. Worn cuffs.
- Eyes: large, tired. Big pupils, small irises.
- Carries a small chalk wand.
- Never speaks — design must read clearly through gesture and expression alone.

**Anti-patterns (must not look like):**
- Disney/Pixar character
- Big-headed chibi
- Minion
- Children's mascot
- Anime
- Discord emoji

**Pass/fail test:** the wizard should look at home in a New Yorker cartoon or an Edward Gorey illustration. He should look out of place in a children's textbook.

## Deliverable 2 — Host Character Sheet

A single board with:

1. Front view (full body, neutral)
2. 3/4 view at the blackboard, chalk in hand, mid-explanation
3. 3/4 view at a desk, looking at a notebook, mid-thought
4. Five expression studies: dry/unimpressed (default), raised eyebrow, slight genuine smile, exasperated (eyes closed, sigh), curious (head slightly tilted)
5. Three pose studies: mid-sentence gesture, holding chalk with two-tap pose ready, brushing chalk dust off hands

**Design constraints:**
- Adult, late 20s to mid 30s read.
- Wearing a henley or rolled-sleeve button-down, work trousers, sensible shoes.
- Glasses optional but useful for thinking beats. If glasses, simple wire frames.
- Always holding a small notebook or tablet, or has chalk in hand.
- Expressions read as dry, observant, slightly skeptical. Not warm-host, not stern-teacher.
- Skin tone, hair, gender presentation: produce a default version, then a second variant. We'll choose later.

## Deliverable 3 — Four Mode Styleframes (one per visual mode)

Each styleframe is a single representative shot from that mode. Showcases the mode's full visual language.

**Mode 1 — Main Animated World styleframe.**
The host's home base. A small workspace: desk, window with daylight, tea or coffee cup, notebook. The host is at the desk, mid-thought. The wizard is hiding behind a stack of books — only the hat poking out. Paper-warm background, soft texture, limited palette.

**Mode 2 — Blackboard styleframe.**
A dark slate board, real chalk feel. Top-left has the wizard's chalk wand resting on the board ledge. Centre has a partial diagram already drawn (Input → Model → Output, roughly). The host is standing to the right, sleeves rolled, chalk in hand, mid-explanation. Chalk dust visible in the air.

**Mode 3 — Interface/Tool styleframe.**
Stylised AI chat interface — invented, not a real product. Background dim. The chat window is paper-coloured against slate. A prompt is typed: "Write a polite email to a client." Below it, a generated reply is partially visible. Cursor is mid-blink. Verify Red highlight on one of the generated sentences indicating "this is the part to check."

**Mode 4 — Human Judgement styleframe.**
A small business setting — a back office of a Perth-style cafe or small workshop. Small business owner at a laptop, looking at an AI-generated email draft. Coffee cup, paperwork, a phone face-down. Slightly more saturated than the main world. Reads as: *real life, real stakes.*

Each styleframe must be a complete, polished frame at 1920×1080. Not concept sketches. Not moodboards. Final-quality.

## Deliverable 4 — Episode 1 Styleframes (10 frames)

Episode 1 centres on: *"Is AI actually magic, or are we just bad at understanding it?"* Frames are in narrative order.

1. **"Is AI magic?"** — bold display type on paper background. Subtle texture. The wizard peeks in from the bottom-right corner, hopeful.
2. **The wizard takes credit** — wizard centre frame, chest puffed, gesturing at a list of things AI supposedly does (write emails, build websites, etc., shown as small chalk-card icons floating around him).
3. **"NO."** — large, single word. Type-driven frame. Wizard's hat has fallen forward.
4. **The wizard's sad walk-off** — wizard from behind, robe dragging, hat slightly tilted, walking left. Small puff of dust. The host watches, unbothered.
5. **"Well… sort of."** — display type, host appearing thoughtful. Wizard peeks back in from the right edge.
6. **"Let's take it to the blackboard"** — host walking toward the blackboard, chalk in hand, sleeves being rolled up. Blackboard is dark and ready.
7. **Input → Model → Output** — full blackboard frame. Diagram drawn in chalk, partially complete. "Input" card on the left ("Write a polite email"), "Model" box in the middle (with small puzzle pieces inside), "Output" forming on the right.
8. **"Useful and wrong at the same time"** — split frame. Left side: an AI output that looks helpful (a polished email). Right side: the same AI output with a hallucinated client name circled in Verify Red.
9. **The Verify Stamp moment** — the stamp coming down hard on a confident-looking AI answer. Stamp is mid-thunk, slight motion blur, dust kicked up.
10. **"AI made clear."** — closing tag frame. Show wordmark on paper background. Wizard sitting on top of one of the letters, defeated but content. Subtle channel mark in the corner.

Each styleframe should feel cinematic, not like a slide. Composition matters. Negative space is welcome.

## Deliverable 5 — Production Asset Manifest

A clean list of every asset needed for Episode 1, organised for handoff to Codex/Remotion. For each asset specify:

- File format (SVG / PNG / Lottie / video)
- Size or aspect ratio
- Whether it animates
- Notes on transparency or layered structure

Categories required:

- **Characters** — host poses (separate body, head, arms layers for rigging), wizard poses (separate body, hat, arms, wand)
- **Props** — chalk wand, notebook, coffee cup, verify stamp, eraser, books, business-context props
- **Backgrounds** — workspace, blackboard (clean and with diagram), business setting, transitional states
- **UI elements** — chat window, prompt bubble, generated reply card, cursor, verify-red highlight overlay
- **Type elements** — the key on-screen lines as illustrated type ("Is AI magic?", "NO.", "Well… sort of.", "AI made clear.")
- **Transitions** — eraser wipe (frame sequence or animated SVG), chalk dust burst, page turn
- **Particles/textures** — chalk dust, paper grain, ink texture, slight fabric grain

**Format guidance for the manifest:**
- Vector-friendly assets that need to scale or animate as a single shape: SVG.
- Complex illustrations with multiple textures, layered painterly work: PNG (with transparent background, layered for compositing).
- Anything with frame-by-frame animation that's not procedural: Lottie or PNG sequence.
- Avoid: rasterising things that should stay vector. Avoid: SVG-ing things that need painterly texture.

## Style Anti-Patterns (Hard Avoid)

- Glowing neural network meshes
- Blue holographic gradients
- Floating UI cards with glassmorphism
- Neon
- Photorealistic anything
- Vector clipart aesthetic
- Stock illustration aesthetic ("two flat people pointing at a chart")
- Childish bright primary colours
- Overlaid drop shadows on everything
- 3D motion graphics blobs
- Anything that looks like a SaaS landing page

---

## Output Format

For each deliverable:

1. Final styleframe(s) at 1920×1080 unless noted otherwise.
2. PNG export with transparency where relevant.
3. Component variants kept as separate Figma components for handoff.
4. Quick written caption per frame: 1–2 sentences on what the frame shows and why it works.

## How to Iterate

I will give critique, not rewrite the brief. If a deliverable fails, I'll point at the specific anti-pattern it triggered or the specific design rule it violated. Re-attempt with that constraint addressed.

Run order recommendation:
1. Mascot character sheet *(this is the highest-risk creative call — get it right first)*
2. Host character sheet
3. Four mode styleframes
4. Episode 1 styleframes
5. Production asset manifest

Don't move to the next deliverable until the previous one passes the brief.
